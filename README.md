# 📦 Installation

Clone repository

```bash
git clone https://github.com/YOUR_USERNAME/full-stack-portfolio.git
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build

```bash
npm run build
```

Start production

```bash
npm start
```
